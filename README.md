#  Heart Disease Prediction App

A Machine Learning web application that predicts the risk of heart disease based on user inputs.

---

##  Live Demo
 https://heart-disease-checker-app.streamlit.app

---

##  Features
- Interactive and user-friendly UI  
- Real-time prediction  
- Confidence score (%)  
- Fast and lightweight ML model (KNN)  

---

##  Tech Stack
- Python  
- Streamlit  
- Scikit-learn  
- Pandas  
- NumPy  
- Joblib  

---

##  How It Works
1. User enters medical details  
2. Data is preprocessed and scaled  
3. KNN model predicts heart disease risk  
4. Result is displayed with confidence score
